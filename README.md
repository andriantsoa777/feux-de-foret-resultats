# Prédire l'ignition des feux de forêt à partir de la météo

Page de résultats du projet de fouille de données (M2 SID, Aix-Marseille Université, 2026–2027).

**Voir la page : https://andriantsoa777.github.io/feux-de-foret-resultats/**

Données, méthode (découpage par mois contre la fuite d'information), comparaison de cinq modèles,
explorateur interactif du seuil, interprétation SHAP, paradoxe de Simpson et k-means.
Données source : US Wildfire Dataset 2014–2025 (Kaggle).
